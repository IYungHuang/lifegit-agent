# LifeSpire (LifeGit Roguelike Tour Engine) 🗺️🃏

> **「將家庭/朋友旅遊規劃，從身心俱疲的責任負擔，轉化為一場《殺戮尖塔》（Slay the Spire）風格的歡樂 Roguelike 爬塔冒險！」**

---

## 🎮 為什麼要「遊戲化 & 卡牌爬塔化」？

排行程傳統上面臨三大困境：
1. **排行程者壓力極大**：做太多功課，現場若小孩哭鬧或排隊過長容易被抱怨（Blame Game）。
2. **缺乏體力與情緒預期**：排得很滿，但不知道全家人的「體力條（HP）」什麼時候會見底崩潰。
3. **現場突發手忙腳亂**：遇到下雨或發燒，行程全毀，不知如何動態重接。

**LifeSpire** 結合了 **Git 狀態機** 與 **《殺戮尖塔》（Slay the Spire）Roguelike 地圖機制**，讓旅遊排程變得像一起在平板上玩派對遊戲！

---

## 🏰 核心機制對應

| 《殺戮尖塔》機制 | LifeSpire 旅遊轉譯 | 旅遊現場效果 |
| :--- | :--- | :--- |
| **頂層 Boss 👑** | **不可取消的 Hard Lock** (如 18:30 晴空塔預約燒肉) | 保證不管白天怎麼分叉冒險，最後一定在對的時間收斂集合！ |
| **精英戰鬥 ⚔️** | **高體力高回報景點** (teamLab 沉浸展、迪士尼暴走) | 體力扣減多 (-24 HP)，但全家回憶與照片經驗值爆表 (+35 EXP)。 |
| **營火休息區 ⛺** | **咖啡廳 / 推車午睡 / 飯店休整** | 選擇：大人喝咖啡補血、二寶推車午休恢復理智線。 |
| **隨機事件 ❓** | **奇遇老店 / 私房打卡小巷** | 「路遇炭烤鯛魚燒老店：花費 ¥600，全員 HP +15，小孩理智 +20%」。 |
| **應變手牌 🃏** | **家庭資源卡** (計程車卡、布丁安撫卡、咖啡營火卡) | 遇到突發狀況直接打牌，扣減金幣與能量，即時換取血量回血。 |
| **詛咒遭遇 ☠️ / Hotfix** | **二寶發燒斷電 / 午後暴雨** | 觸發緊急 Rebase，AI 自動修剪下午路線，排入專車與飯店休息，保住晚餐 Boss。 |
| **分支決策 Diff ⚖️** | **A/B 路線預測矩陣** | 在大螢幕上一眼比對台場（進攻流）vs 橫濱（幼兒防禦流）的體力、步數與花費差。 |
