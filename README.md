# LifeSpire 好好放假旅行社

Steam 遊戲版的首場單人試玩：玩家扮演旅行社企劃，用有限手牌安排東京一日遊，應付「終於請到假的上班族」阿哲。這個分支提供旅行題材娛樂；實用旅行規劃工具另在 `codex/web-travel-tool` 開發。

## 本機試玩

在專案目錄執行：

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

以瀏覽器開啟 [本機遊戲](http://127.0.0.1:8080)。本版使用 JavaScript modules，請透過 HTTP 開啟，不要直接雙擊 `index.html`。遊玩不需要安裝 npm 套件；背景、立繪、卡圖、字體都存放在本機，啟動後不依賴外網服務。按 Ctrl+C 停止伺服器。

## 怎麼玩

1. 開始接案，點擊或按空白鍵讀完客戶需求。
2. 選一張手牌，再點亮起的行程位置。上午放景點、午餐放餐飲、下午放景點或休息。
3. 交通牌放在行程之間，替換該段預設交通；撤回與重排不扣資源。
4. 檢查預算、疲勞、晚餐抵達時間。尚未排完時顯示暫估，不能提交。
5. 必要時換牌（每案 2 次），或準備話術（每案一次，免除一次不合格提案的精神扣減）。
6. 提交後看客戶反應。滿足必要條件即成交；精神歸零則破局。額外達成拍照與休息願望會提高評價。

鍵盤支援 Tab 與 Enter 操作、Escape 取消選取／關閉需求、空白鍵補完台詞與繼續。右上方可切換音效與減少動態。重新接案保留這兩項偏好，不保存中途行程。

## 開發與測試

Node.js 22 或更新版本：

```sh
npm ci
npm test
```

測試使用 Node 內建 runner；jsdom 是僅供測試的開發依賴，不會載入遊戲。遊戲程式分為案件資料、純規則、牌池、狀態機、對話、演出與視圖。
