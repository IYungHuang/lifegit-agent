# Steam 首場試玩驗收紀錄

2026-10-06。實作位於 `codex/steam-travel-game`，本次已完成程式與素材，實際瀏覽器視覺與音效驗收待完成。

## 已驗證

- Node.js 22.23.1，`npm test`：30 項單元、資源與 DOM 整合測試。
- 枚舉 744 種可產生的起手牌，以及 23,762 個可用的起手換牌選項；皆保留至少一組能成交的行程。
- 按順序計算休息與交通疲勞；預算、抵達時間、疲勞等於上限可成交。
- 真實卡池可產生遲到、超預算或疲勞超標的方案。
- DOM 操作完成開場、安排、成交及重啟；連續三次退件可破局，重啟恢復手牌與精神。
- 提交鎖定、一次性話術、取消舊打字回呼、忽略長按空白、Escape、需求面板焦點與偏好保留。
- 對話中切換減少動態後，當句及後續句子不再逐字顯示。
- 素材清單遺失／格式錯誤時以預設本機路徑啟動；圖片遺失顯示警告，仍可遊玩。
- 音訊啟動被拒絕、設定儲存失敗不阻斷遊戲。
- 18 張 PNG 已讀取驗證，角色具透明通道，Noto Sans TC 與 OFL 授權檔存在。
- 入口及 CSS 沒有遠端執行時資源引用，`git diff --check` 通過。

## 獨立審查

一次 gpt-6-astra 獨立程式審查發現三項 P2：動態偏好未更新進行中的對話、缺失 manifest 導致無法遊玩、必要標籤字級過小。三項皆已建立失敗測試後修正；已重新跑完整測試。

審查未操作瀏覽器。jsdom 能驗證 DOM 事件與狀態，不能證明 CSS 排版、圖片合成或實際音效正確。

## 執行時調整

- 沿用使用者指定的 Steam 分支與工作目錄，未再建立 worktree；不修改網頁工具分支。
- 加入 jsdom 開發依賴以測 DOM 流程，正式遊戲無 runtime 套件依賴。這不取代瀏覽器驗收。
- 購物卡由 180 分鐘調整為 240 分鐘：原卡池最晚只到 17:50，無法觸發 18:30 的期限。此調整啟用時間取捨，實際難度仍需試玩調校。
- 卡牌風味短句移至滑鼠提示，將卡面空間留給必要規則；觸控玩家仍能讀到所有遊戲效果。
- 規則、牌池及狀態等測試按計畫先見到缺模組失敗，再由實作通過；沒有將原本不存在的測試套件描述為既有基線。

沒有延後處理的程式審查 minor finding；上述人工驗收仍未完成，不能稱為正式發行驗收通過。
